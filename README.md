# 👑 Hyperion AI Quant Terminal (Grid Bot)

비트겟(Bitget) 선물 전용 무한 DCA 그리드 퀀트 트레이딩 터미널 공식 배포소입니다.

- **최신 릴리즈 버전**: `v8.28.0`
- **배포 형태**: 윈도우 정식 설치 마법사 (`Hyperion_Quant_Setup_v8.28.0.exe`)
- **주요 기능**:
  - 🖥️ **정식 윈도우 설치 프로그램**: 바탕화면 바로가기, 시작 메뉴 등록, 제어판 언인스톨러
  - 🤖 **스토캐스틱 RSI (14, 14, 3, 3) 5m/15m 스마트 바닥 매집 필터**
  - 📊 **Lightweight Charts 1:1 무지연 실시간 캔들스틱 & 0~100 서브차트 동기화**
  - 🛡️ **비트겟 공식 V2 파트너십 API 직결 100% 무인 전자동 VIP 라이선스 게이트키퍼**
  - 🚀 **온라인 실시간 원클릭 자동 업데이트(Auto-Updater) 및 원격 버전 동기화**
- **공식 다운로드**: [Releases](https://github.com/NaThanAEL7912/grid_bot/releases)
